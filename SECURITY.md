# Security Policy

Do not open a public issue containing vulnerability details, credentials, access tokens,
private server information, or exploit material that would create avoidable risk.

If GitHub's **Report a vulnerability** option is enabled for this repository, use that
private channel. Otherwise, contact the repository owner privately before sharing sensitive
technical details.

Security reports should concern Apothic Ascension itself. Issues in Minecraft, NeoForge,
Apotheosis, or another dependency should normally be reported to that upstream project unless
Apothic Ascension introduces or materially worsens the condition.
