# Contributing

This repository is the public source boundary and issue tracker for Apothic Ascension.

## Issues

Use the provided issue forms when possible. A useful report includes exact versions, the
smallest reliable reproduction, and relevant logs.

## Pull requests

The authoritative development history is maintained separately. Pull requests may be used
as proposed patches, but a maintainer may reproduce or integrate the change in the private
development repository before it appears in a later public source snapshot.

Do not depend on private branch names, unpublished roadmaps, internal CI behavior, or
qualification tooling when preparing a contribution.
