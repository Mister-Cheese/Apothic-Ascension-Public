# Contributing

Apothic Ascension uses this repository as its public source mirror and issue tracker.

## Issues

Please use the provided issue forms and include enough information to reproduce the
problem. Compatibility reports should include exact versions for Minecraft, NeoForge,
Apothic Ascension, Apotheosis, and the interacting mod.

## Pull requests

Pull requests are welcome as proposed patches, but this repository is not the authoritative
development history. A maintainer may reproduce or integrate a change in the private
development repository and publish the resulting source in a later export.

Do not rely on private branch names, internal CI behavior, qualification tooling, or
unpublished implementation plans when preparing a contribution.
